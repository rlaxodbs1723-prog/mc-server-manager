MC CubePanel

개인정보 처리방침

시행일: 2026년 11월 12일

MC CubePanel(이하 "앱")은 서버와 파일을 모두 내 컴퓨터에 저장해요. 바깥으로 보내는 정보는 아래 기능을 쓸 때 필요한 만큼만이에요. 서버 파일, 월드, 채팅 기록은 앱 운영자에게 보내지 않아요.

1. 쓰는 정보와 이유

기능쓰는 정보이유보관 기간
사용 통계앱을 켜거나 서버를 만들고 켠 횟수, 앱 버전 (이름·IP 같은 개인 정보는 저장하지 않음)앱이 얼마나 쓰이는지 알기 위해통계 서비스 보관 기간
이름 주소정한 이름, 서버 컴퓨터의 공인 IP 주소, 포트, 마지막 접속 시각, 기기 구분용 무작위 표식이름 주소를 내 서버로 연결하기 위해이름을 쓰는 동안. 오래 쓰지 않거나 놓으면 삭제
버그 제보직접 쓴 내용, 직접 붙인 사진·영상, 앱 버전, Windows 버전문제를 고치고 답장하기 위해처리가 끝날 때까지 (운영자 디스코드 채널)
서버 공유공유 방 번호, 초대 코드·기기 열쇠의 해시(원래 값은 저장하지 않음), 기기별 권한, 접속 시각친구 앱과 내 앱을 연결하고 권한을 지키기 위해공유를 끝내거나 기기를 내보낼 때 삭제
로그인 (서버 공유를 쓸 때만)로그인 방식(Discord 또는 Google), 계정 고유 번호, 표시 이름, 이메일 주소공유하는 사람과 들어오는 사람을 확인하고 악용을 막기 위해계정을 지울 때까지

서버 공유 중 오가는 콘솔 로그·명령·플레이어 목록은 두 앱 사이를 중계만 하고 저장하지 않아요. 비밀번호는 앱과 운영자 모두 받지 않아요. 로그인은 Discord·Google 화면에서 직접 해요.

2. 정보를 맡기는 곳

앱 운영에 필요한 아래 서비스에 정보를 맡겨요. 그 밖의 곳에 팔거나 넘기지 않아요.

  • Cloudflare: 사이트, 이름 주소, 서버 공유 중계, 계정 저장
  • GoatCounter: 익명 사용 통계
  • Discord: 버그 제보 전달, Discord 로그인
  • Google: Google 로그인
  • GitHub: 앱 내려받기와 업데이트 확인

이 서비스들은 해외(주로 미국)에 서버가 있어서 정보가 국외로 옮겨질 수 있어요.

3. 내가 할 수 있는 것

  • 사용 통계 끄기: 앱 설정 → 개인 정보

Privacy Policy (English summary)

MC CubePanel keeps your servers, worlds and chat logs on your own computer. It only sends what a feature needs:

  • Usage stats (anonymous launch and server counts, app version). You can turn this off in App settings → Privacy.
  • Name addresses: the name, your server's public IP and port, last seen time, a random device tag. Deleted when you release the name or stop using it.
  • Bug reports: what you write and attach, app and Windows versions.
  • Server sharing: room ID, hashed invite and device keys, roles. Console logs and commands are relayed, never stored.
  • Sign-in (server sharing only): provider (Discord or Google), account ID, display name, email address. Used only to identify who shares and joins and to prevent abuse. Deleted when you delete your account in the app.

Processors: Cloudflare, GoatCounter, Discord, Google, GitHub. We never sell your data. Users under 14 need a guardian's consent to use sign-in. Contact: GitHub issues.
